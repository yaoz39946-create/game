# Snake Game

A simple terminal-based Snake game implemented with Python's `curses` library.

## Prerequisites
- Python 3.9+
- A terminal that supports `curses` (most Unix terminals do).

## How to play
1. Run the game:
   ```bash
   python snake.py
   ```
2. Control the snake with the arrow keys.
3. Press `q` to quit at any time.

The score is shown at the top of the screen, and the game ends if the snake hits a wall or itself.
